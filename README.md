- 읽기 시작: [wiki/index.md](wiki/index.md)
- 운영 규칙: [AGENTS.md](AGENTS.md)
- 점검: `node scripts/lint.mjs`

| --- | --- |
| `raw/` | 원문 사본 (Figma 기획, 회의 요약, 노션 글). 구속력 없음 |
| `wiki/` | 정리본. 에이전트가 쓰고 사람이 PR로 승인 |
