# Figma 기준 페이지

디자인과 기획의 기준은 **최종 페이지 하나**다. 같은 파일의 다른 페이지에는 예전 시안이 섞여 있으므로 수집하지도, 구현 근거로 쓰지도 않는다.

- 파일: `cxHU1PY93XePE80n7R3IAm` (우두머리 FIGMA)
- 기준 페이지: `10. 최종 디자인 정리 ✅` — 노드 `3042:26885`
- [열기](https://www.figma.com/design/cxHU1PY93XePE80n7R3IAm/?node-id=3042-26885)

## 규칙

- Figma에서 가져오는 모든 것(기획 패널, 화면, 수치)은 이 페이지 안의 노드여야 한다. 다른 페이지의 노드 URL을 받으면 기준 페이지에 같은 화면이 있는지 먼저 확인한다.
- 기획 패널은 화면 옆의 `description` 프레임(폭 500)이다. 사본은 `raw/figma/SPEC-nn-이름.md`로 둔다.
- 노드 ID는 복사·이동으로 바뀔 수 있다. 못 찾으면 영역과 프레임 이름으로 다시 찾고 사본의 노드 ID와 확인일을 갱신한다.
- 디자인 시스템(토큰, 컴포넌트)은 아직 수집하지 않았다. 추가할 때 `design/` 아래에 이름 매핑만 두고 값은 저장하지 않는다.
