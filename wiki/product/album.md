# 여행 앨범·사진 뷰어

## 흐름

1. 앨범 목록에서 방문한 지역마다 카드 1장을 본다 (SPEC-11 §2)
2. 카드를 누르면 지역 상세로 간다. 헤더, 키워드 칩, 멤버별 기록 카드 그리드가 있다 (SPEC-11 §2, SPEC-12 §2~§4)
3. 기록이 있는 카드를 누르면 사진 뷰어로 간다. 내가 미기록이면 내 카드에서 업로드로 들어간다 (SPEC-12 §4-1, §4-3)
4. 뷰어에서 좌우 스와이프로 같은 지역의 사진을 넘긴다 (SPEC-13 §5)
5. 내 사진이면 더보기 → 수정하기 / 삭제하기 (SPEC-13 §2, §2-1)

## 규칙

### 앨범 목록

- 드롭다운은 지도 뷰의 것과 기능·디자인이 같다. 팟을 바꾸면 카드 리스트 전체가 그 팟 기준으로 갱신된다 (SPEC-11 §1)
- 카드 구성: 지역명 + 기록 인원수 "N/N명" + 이미지 모음 + Alert(선택) (SPEC-11 §2)
- 기록 인원수는 팟 멤버 수 중 사진을 올린 인원 수다. 예: 4명 중 3명이면 "3/4명" (SPEC-11 §4)
- 카드의 이미지 개수는 팟 멤버 수와 같다 (SPEC-11 §5)
- 이미지 순서는 좌측부터 팟에 들어온 순서(가입 순)로 고정 배정한다 (SPEC-11 §5)
- 올린 사람 자리는 사진만 보인다. 안 올린 사람 자리는 Zzz 아이콘과 점선이다 (SPEC-11 §5)
- 사람을 구분하는 뱃지·아바타는 없다. 위치가 곧 그 사람의 자리다 (SPEC-11 §5)
- Alert "아직 기록하지 않은 여행이 있어요"의 원문 조건은 "이 지역의 과거 방문 건 중 내가 올리지 않은 여행이 하나라도 남아 있을 때"다 (SPEC-11 §3). 재방문 개념이 없어졌으므로(D-003) 이 조건을 "내가 이 지역에 기록하지 않았을 때"로 읽을지는 [Q08](../open-questions.md#q08)
- 내가 업로드를 완료하면 미기록 카드는 사라지고 기록 카드 + ME! 뱃지로 바뀐다 (SPEC-12 §4-1)
- 사진 삭제 완료 후에는 이전 화면으로 돌아간다. 마지막 1장을 삭제하면 상위 리스트 화면으로 돌아간다 (SPEC-13 §2-4, §2-1)
- GNB의 지구본은 지도 뷰, 마이페이지는 마이페이지 메인으로 간다 (SPEC-11 §6, §7)

### 지역 상세

- 헤더: 지역명 + 멤버 프로필 아이콘 + "n/N명 기록 완료". n = 그 지역에 사진을 올린 멤버 수, N = 팟 전체 멤버 수 (SPEC-12 §2)
- 카운터는 업로드·삭제 시 실시간 반영한다 (SPEC-12 §2)
- 프로필과 카드의 순서는 나 최상단 고정 → 이후 가입 순서다 (SPEC-12 §2, §4)
- 프로필 테두리는 업로드한 멤버가 실선, 안 한 멤버가 점선이다 (SPEC-12 §2)
- 키워드 칩은 그 지역 사진의 키워드를 종류별로 집계한다. 숫자는 해당 키워드로 등록된 사진 수다 (SPEC-12 §3)
- 기록이 0개인 지역에서는 칩 영역을 보이지 않는다 (SPEC-12 §3)
- 그리드는 1인팟이면 1열 풀폭 카드, 2인팟 이상이면 2열이다 (SPEC-12 §4)
- 내 미기록 카드: 프로필 + 닉네임 + ME! 뱃지 + [+ 내 사진 올리기]. 누르면 그 지역의 업로드 플로우로 간다 (SPEC-12 §4-1)
- 타인 미기록 카드: 프로필 + 닉네임 + zzZ 그래픽만 있고 클릭 액션이 없다 (SPEC-12 §4-2)
- 기록 카드: 사진 1장 + 프로필/닉네임 + 코멘트 + 우상단 키워드 스티커. 코멘트는 최대 2줄, 넘으면 말줄임 (SPEC-12 §4-3)
- ME! 뱃지는 기록 유무와 무관하게 본인 카드에만 붙는다 (SPEC-12 §4-4)

### 사진 뷰어

- 더보기 버튼은 본인이 올린 사진에만 보인다. 타인 사진에서는 숨긴다 (SPEC-13 §2)
- 나가기 버튼은 이전 화면으로 간다. 수정/삭제 드롭다운이 열려 있으면 드롭다운부터 닫는다 (SPEC-13 §1)
- 수정하기는 수정 화면(여행 기록)으로 간다. 수정 완료 토스트를 3초 보이고 내용을 즉시 반영한다 (SPEC-13 §2-1, §2-2)
- 삭제하기는 확인 팝업을 띄운다. 닫기(X)와 취소는 팝업을 닫고 원래 화면을 유지한다 (SPEC-13 §2-3)
- 팝업에서 삭제를 누르면 삭제하고 삭제 완료 토스트를 3초 보인다 (SPEC-13 §2-3, §2-4)
- 닉네임 뱃지는 업로더의 프로필 아이콘 + 닉네임이다. 본인 사진이면 "ME!"를 함께 보인다 (SPEC-13 §3)
- 사진 하단 툴팁에 업로더의 키워드 아이콘과 코멘트를 보인다 (SPEC-13 §4)
- 사진 영역을 누르면 헤더·뱃지·툴팁을 숨겨 전체화면이 되고, 다시 누르면 돌아온다 (SPEC-13 §5)
- 좌우 스와이프는 동일 지역 안에서만 다음/이전 사진으로 간다 (SPEC-13 §5)
- 이미지 로드 실패 시 다시 시도 버튼을 보인다. 누르면 재요청하고 성공하면 정상 이미지로 바꾼다 (SPEC-13 §6)

## 확인 필요

- 이미지·카드 순서가 목록은 "가입 순 고정", 상세는 "나 최상단 → 가입 순"이다. 화면별로 다른 것이 의도인지 확인 필요 (SPEC-11 §5, SPEC-12 §4)
- 취소 클릭 결과가 "드롭다운 닫고"와 "팝업 닫고"로 다르게 적혀 있다 (SPEC-13 §2-1, §2-3)
- 수정·삭제 완료 토스트의 문구, 삭제 확인 팝업의 문구는 사본에 없다 (SPEC-13 §2-2, §2-3, §2-4)
- "1인팟에서 본인 미기록이면 접근 불가"라는 전제는 앨범 진입 조건이 확정돼야 성립한다. [Q07](../open-questions.md#q07) (SPEC-12 §4)
- 스와이프 순서, 미기록 멤버를 건너뛰는지는 원문에 없다 (SPEC-13 §5)
