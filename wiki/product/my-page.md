# 마이페이지

## 흐름

1. 닉네임 수정을 누르면 프로필 수정 화면으로 간다 (SPEC-16 §1)
2. 닉네임·아바타를 바꾸고 [저장] → 마이페이지로 돌아온다 (SPEC-16 §4, §4-2)
3. 내 팟 목록, 이용약관·개인정보처리방침 링크를 본다 (SPEC-16 §2, §3)
4. [로그아웃] → 확인 팝업 → 스플래시 화면 + 완료 토스트 (SPEC-16 §5, §5-1, §6)
5. [계정 삭제] → 재확인 팝업 → 스플래시 화면 + 완료 토스트 (SPEC-16 §7, §7-1, §8)

## 규칙

### 내 팟·약관

- 내 팟 리스트는 가장 최근에 들어온 팟이 최상단이다 (SPEC-16 §2)
- [이용약관] / [개인정보처리방침]을 누르면 노션 페이지로 연결한다 (SPEC-16 §3)

### 프로필 수정

- 기존에 입력한 닉네임·아바타가 그대로 채워진 상태로 진입한다 (SPEC-16 §4)
- 카메라 아이콘은 사진 업로드이며 온보딩과 동일하다 (SPEC-16 §4)
- 닉네임 규칙은 온보딩(회원가입)과 동일하다. 규칙은 [로그인·회원가입·온보딩](auth-onboarding.md)에 있다 (SPEC-16 §4, §4-1)
- [저장]은 닉네임 또는 아바타 중 하나라도 기존 값과 달라지면 활성화한다 (SPEC-16 §4-1)
- 둘 다 기존 값과 같으면 비활성을 유지한다 (SPEC-16 §4-1)
- 이미 선택된 아바타를 다시 누른 것은 변경 없음으로 처리한다 (SPEC-16 §4-1)
- [저장]을 누르면 저장 후 마이페이지로 간다 (SPEC-16 §4-2)
- 변경사항이 있는 상태에서 [저장] 없이 뒤로가기를 누르면 변경사항을 반영하지 않고 마이페이지로 간다 (SPEC-16 §4-2)
- 변경사항이 없는 상태의 뒤로가기도 마이페이지로 간다 (SPEC-16 §4-2)

### 로그아웃

- [로그아웃]을 누르면 확인 팝업을 보인다 (SPEC-16 §5)
- 팝업의 [로그아웃]은 로그아웃 후 스플래시 화면으로 간다. [취소]는 팝업을 닫고 마이페이지를 유지한다 (SPEC-16 §5-1)
- 스플래시 화면 진입 후 "로그아웃이 완료됐어요." 토스트를 보인다 (SPEC-16 §6)

### 계정 삭제

- [계정 삭제]를 누르면 재확인 팝업을 보인다 (SPEC-16 §7)
- 계정 삭제는 현재 유예 기간 없이 즉시 처리된다(`be:.../user/service/AccountWithdrawalService.kt`). 방침 7조는 사용자, 소셜 계정 연결, refresh 토큰, 업로드한 이미지, 그 사용자의 여행 기록을 삭제한다고 약속한다. 삭제 뒤 복원 기능을 넣으려면 방침과 맞는지 먼저 확인한다 (notion:privacy-policy 7조)
- 피드백은 별점·본문·사용자 ID·앱 버전·기기 정보·전송 시각을 저장하고, 계정 삭제가 피드백 행을 지우지 않는다. 방침에 피드백 항목이 없다 ([Q21](../open-questions.md#q21))
- 팝업의 [계정 삭제]는 삭제 후 스플래시 화면으로 간다. [취소]는 팝업을 닫고 마이페이지를 유지한다 (SPEC-16 §7-1)
- 삭제 시 해당 유저가 업로드한 사진을 삭제한다 (SPEC-16 §7-1)
- 삭제 시 해당 유저가 속한 모든 여행팟에서 탈퇴 처리하고 그 자리는 공석으로 바꾼다. 여행팟 자체는 유지한다 (SPEC-16 §7-1)
- 스플래시 화면 진입 후 "계정 삭제가 완료되었습니다. 감사합니다." 토스트를 보인다 (SPEC-16 §8)

## 확인 필요

- 계정 삭제 항목의 제목이 "로그아웃 버튼"으로 적혀 있다. 본문은 계정 삭제 내용이라 제목 오기로 보인다 (SPEC-16 §7)
- 저장 버튼이 활성화되려면 변경된 닉네임이 유효해야 하는지는 "닉네임 가능 조건은 회원가입 시와 동일"로만 적혀 있다. 변경 조건과 유효 조건을 함께 적용하는지 확인 필요 (SPEC-16 §4-1)
- 변경사항이 있는 채 뒤로가기를 누르면 "변경사항 미반영 상태로 마이페이지 이동"이라고만 적혀 있다. 이탈 확인을 띄울지는 원문에 없다 (SPEC-16 §4-2)
- 로그아웃·계정 삭제 완료 토스트의 노출 시간은 원문에 없다 (SPEC-16 §6, §8)
- 프로필 저장 완료 토스트, 저장 실패 처리는 원문에 없다 (SPEC-16 §4-2)
- "공석"이 된 자리가 앨범의 멤버 수·이미지 자리, 정원(n/6) 계산에 어떻게 반영되는지 원문에 없다 (SPEC-16 §7-1)
- 계정 삭제는 "업로드한 사진 삭제"로 적고, 팟 나가기 쪽은 삭제 범위가 모순된다. 두 정책을 맞출지는 [Q17](../open-questions.md#q17)과 함께 본다 (SPEC-16 §7-1, SPEC-17 §6-1)
- 내 팟 리스트에서 팟을 눌렀을 때의 이동(팟 편집 화면인지)은 이 원문에 없다 (SPEC-16 §2)
