# 여행 기록 업로드

## 흐름

1. 키워드 칩 중 1개를 고르고 [다음]을 누른다 (SPEC-09 §3, §4)
2. [사진 추가하기] → OS 사진 라이브러리에서 1장을 고르면 대표 사진 자리에 반영된다 (SPEC-09 §6, §6-1)
3. 코멘트를 적거나 비워 두고 [확인]을 누른다 (SPEC-10 §7, §8)
4. 미리보기 화면에서 지역명 뱃지, 키워드, 업로더, 사진, 코멘트를 확인한다 (SPEC-10 §9~§13)
5. [지도에 기록하기] → 지도에 반영되고 완료 토스트가 뜬다 (SPEC-10 §14, §15)

## 규칙

### 키워드 선택

- 키워드는 맛집 / 디저트 / 힐링 / 액티비티 / 사진 다섯 가지이고 1개만 고른다 (SPEC-09 §3)
- 칩을 고르면 강조 표시로 바뀌고, 다른 칩을 고르면 선택이 그쪽으로 옮겨간다 (SPEC-09 §3-1)
- [다음]은 키워드를 선택한 뒤에 활성화한다 (SPEC-09 §4)
- 이 화면의 지역명 뱃지는 지역명만 보인다. 키워드 색상을 반영하지 않는다 (SPEC-09 §2)
- 뒤로가기는 이전 화면으로 간다 (SPEC-09 §1)

### 사진 선택

- 앞 화면에서 고른 키워드가 사진 프레임 좌상단의 알약형 칩(아이콘 + 키워드명)으로 그대로 넘어온다 (SPEC-09 §5)
- [사진 추가하기]는 플레이스홀더 영역 중앙에 "+" 아이콘과 텍스트로 놓이고, 누르면 갤러리로 간다 (SPEC-09 §6)
- 사진은 1장을 고른다 (SPEC-09 §6-1)
- 사진 장수 제한은 비용 절감을 위해 도입됐다. 당시는 하루 1장이었고 지금은 지역당 1장이다 (meeting:2026-06-11)
- 사진 선택 화면의 안내 문구는 키워드 이름을 넣지 않고 "사진 1장을 남겨주세요" 형태로 쓴다 (meeting:2026-08-31)

### 코멘트

- placeholder는 "사진 한 줄 설명을 적고 친구와 공유해요"다 (SPEC-10 §7)
- 코멘트는 선택 입력이다. 코멘트 없이 사진만 있어도 [확인]이 활성화된다 (SPEC-10 §7, §8)

### 미리보기와 완료

- 미리보기의 지역명 뱃지는 선택한 키워드에 지정된 색상을 배경으로 쓴다 (SPEC-10 §9)
- 키워드명은 "OOO!투어" 형식(예: "디저트!투어")으로, 밑줄과 뱃지와 같은 키워드 컬러를 적용한다 (SPEC-10 §10)
- 미리보기에 진입하면 키워드 옆 이모지가 "빵!" 터지는 연출을 한다 (SPEC-10 §10)
- 업로드한 사람의 프로필 이미지와 닉네임, 앞에서 고른 이미지를 보인다 (SPEC-10 §11, §12)
- 코멘트는 사진 아래 말풍선(포인터가 사진 쪽)에 키워드 스티커 아이콘과 함께 보인다 (SPEC-10 §13)
- [지도에 기록하기]를 눌러야 실제 지도에 반영된다 (SPEC-10 §14)
- [지도에 기록하기] 버튼은 스크롤하지 않아도 보여야 한다 (D-010)
- 완료 토스트는 사진 업로드와 지도 기록이 끝난 직후 뜬다. 문구는 "'지역' 여행 Pinned 완료!"다 (SPEC-10 §15)

## 확인 필요

- 사진을 고르기 전 [확인]의 상태는 "사진만 올려도 활성화"에서 미루어 볼 수 있을 뿐 직접 적혀 있지 않다 (SPEC-10 §8)
- 코멘트를 비웠을 때 미리보기의 말풍선을 숨기는지 원문에 없다 (SPEC-10 §13)
- 키워드별 색상 표는 사본에 없다. 예시로 디저트가 레드라는 것만 나온다 (SPEC-10 §9, §10)
- 미리보기에서 뒤로 가 키워드·사진을 바꿀 수 있는지, 업로드 도중 이탈 시 입력값 처리는 원문에 없다 (SPEC-10 §8)
- 기록 수정 화면은 사진 뷰어의 "수정하기"가 가리키지만 이 두 원문에는 수정 흐름이 없다 (SPEC-09 §3, SPEC-10 §7)
- 이미 내가 기록한 지역에 다시 올리는 경우는 이 원문에 없다 (SPEC-09 §6-1). 결정상 다시 기록하면 내 기록을 통째로 바꾼다 (D-003)
