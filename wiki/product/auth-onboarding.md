# 로그인·회원가입·온보딩

## 흐름

1. 카카오 로그인 버튼으로 로그인한다 (SPEC-01 §1)
2. 회원가입 페이지에 들어오면 서비스 접근 권한 확인 팝업이 바로 뜬다 (SPEC-01 §7)
3. 아바타를 고르거나 앨범 사진을 올리고 닉네임을 입력한다 (SPEC-01 §2~§5)
4. [완료] → 회원가입 완료 화면에서 [확인] → 설명 온보딩 페이지 (SPEC-01 §6, §8)
5. 온보딩은 CTA 또는 스와이프로 다음 페이지로 넘긴다 (SPEC-01 §9)

## 규칙

### 로그인

- 로그인 성공 시 자동 로그인을 유지한다. 유지 기간은 15일 / 30일 중 미확정이다 (SPEC-01 §1)

### 프로필

- 기본 프로필 이미지는 4종이고, 화면 진입 시 첫 번째 아바타가 선택된 상태다 (SPEC-01 §2, §4)
- 다른 아바타를 누르면 선택 상태가 그쪽으로 옮겨간다 (SPEC-01 §4)
- 카메라 아이콘을 누르면 앨범 이미지를 올릴 수 있다 (SPEC-01 §3)

### 닉네임

- 길이는 최소 1자, 최대 6자이며 공백을 포함해 센다 (SPEC-01 §5)
- 6자를 넘겨도 입력 자체는 된다(직접 입력·붙여넣기 동일). 넘으면 "닉네임은 최대 6글자까지 가능해요" 에러를 보이고 [완료]를 비활성화한다 (SPEC-01 §5)
- 공백만 입력하면 무효이고 에러를 보인다 (SPEC-01 §5)
- 중복 닉네임을 허용하고 특수 기호도 쓸 수 있다 (SPEC-01 §5)
- 에러 검증은 입력 중 실시간으로 한다 (SPEC-01 §5)
- 닉네임 미입력이면 [완료]는 비활성이다 (SPEC-01 §2)
- [완료]는 닉네임 6자 이하 조건을 충족할 때만 활성화한다 (SPEC-01 §6)

### 접근 권한 팝업

- 서비스 접근 권한 확인 팝업은 회원가입 페이지 진입 시 바로 뜬다 (SPEC-01 §7)
- 이 팝업에서 [취소]를 누르면 필수 권한 허용 권장 팝업을 보인다 (SPEC-01 §7)
- 권장 팝업은 필수 권한(앨범 등)을 허용하지 않은 채 재진입할 때 보인다 (SPEC-01 §7-1)
- 권장 팝업의 [지금 설정]은 기기 설정 앱으로 이동하고, 취소 아이콘은 팝업을 닫는다 (SPEC-01 §7-1)

### 로딩 화면

- 심볼만 움직이고 "Loading" 텍스트와 부제 텍스트는 고정이다 (SPEC-18 §1)
- 움직임은 translateY 0px → -5px → 0px 수직 이동뿐이다. 회전·스케일은 없다 (SPEC-18 §1)
- duration 0.8s, easing ease-in-out, 로딩이 끝날 때까지 무한 반복한다 (SPEC-18 §1)
- 화면 진입과 동시에 시작한다 (SPEC-18 §1)

## 확인 필요

- SPEC-18의 노드는 [Figma 기준 페이지](../design/figma-baseline.md) 안에서 찾지 못했다. 기준에 포함되는지 확인하기 전에는 로딩 화면 규칙을 근거로 쓰지 않는다
- 로딩 심볼을 한 문단 안에서 "하트 심볼"과 "핀 심볼"로 다르게 부른다. 대상이 무엇인지 확인 필요 (SPEC-18 §1)
- 앨범 첫 진입 시 권한 팝업을 "(3-1)"로 가리키지만 그 번호의 항목이 없다. 회원가입 진입 즉시 뜨는 §7 팝업과 같은 것인지, 노출 시점이 어느 쪽인지 확인 필요 (SPEC-01 §3, §7)
- 권장 팝업의 노출 조건이 "[취소] 클릭 시"와 "미허용 상태에서 재진입 시" 두 가지로 적혀 있다. 둘 다인지 확인 필요 (SPEC-01 §7, §7-1)
- [완료] 활성 조건을 §6은 "6자 이하"로만 적는다. 미입력·공백만 입력은 §2·§5가 따로 막으므로 세 조건을 함께 적용하는지 확인 필요 (SPEC-01 §2, §5, §6)
- 로그인 실패·취소, 온보딩 페이지 수와 마지막 페이지 이후의 이동은 원문에 없다 (SPEC-01 §1, §9)
