# 여행팟 (진입·생성·참여·설정)

## 목적

여행팟을 만들거나 초대코드로 참여하고, 팟 사이를 전환하며, 이름·멤버·초대·삭제·나가기를 관리한다.

## 흐름

1. 참여 중인 팟이 0개면 메인 진입 시 전용 화면에서 [새 팟 만들기] 또는 [초대코드로 참여하기]를 고른다 (SPEC-02 §1, §3, §4)
2. 생성: 이름 입력 → [팟 만들기] → 티켓 화면 → 닫기(X) → 여행 지도 (SPEC-03 §2~§6)
3. 참여: 초대코드 6자리 → [참여하기] → 팟 정보 확인 → [맞아요] → 여행 지도 + 참여 토스트 (SPEC-04 §2, §3, §7, §9, §10)
4. 전환: 메인 홈 상단 팟 이름 → 드롭다운 → 다른 팟 선택 (SPEC-02 §5)
5. 설정: 팟 설정 화면에서 이름 수정, 초대, 삭제, 나가기 (SPEC-17 §1~§6)

## 규칙

### 진입·전환

- 전용 진입 화면은 어떤 팟에도 속하지 않은 최초 상태에서만 나온다 (SPEC-02 §1)
- 진입 화면의 뒤로가기는 온보딩 페이지로 간다 (SPEC-02 §2)
- 드롭다운은 내가 참여 중인 팟 목록을 보이고, 현재 보고 있는 팟에 체크 아이콘을 붙인다 (SPEC-02 §5)
- 드롭다운의 팟 이름은 글자수 제한 없이 보이되 2줄을 넘으면 말줄임 처리한다 (SPEC-02 §5)

### 생성

- 이름 입력 placeholder는 "우리 팟의 이름을 입력해 주세요."다 (SPEC-03 §2)
- 이름은 최대 글자수 제한이 없고 공백 포함 가능하며, 개발단에서 임의 지정할 수 있다고 적혀 있다 (SPEC-03 §2)
- 중복 이름을 허용하고 특수기호를 쓸 수 있다 (SPEC-03 §2)
- [팟 만들기]는 1자 이상 입력 시 활성화한다(공백도 가능). 미입력이면 비활성이다 (SPEC-03 §3)
- 티켓에는 팟 이름, 진입 순서(생성자는 고유 1번), 팟장 닉네임, 팟 생성 당일 날짜, 초대코드를 보인다 (SPEC-03 §6)
- 최대 인원 툴팁은 첫 생성 후 그 페이지에서 상시 노출하고(자동 사라짐 없음) 현재/최대 인원(1/6)을 실시간 반영한다 (SPEC-03 §7)
- [초대코드 공유하기]는 시스템 공유 바텀시트를 연다 (SPEC-03 §8)
- 닫기(X)는 신규 팟의 첫 진입 화면인 여행 지도로 간다 (SPEC-03 §4)
- [시작하기]를 누르면 안내 문구(STEP 1/2)가 사라지고 지도가 보이며 동시에 전국 → 서울로 줌인한다 (SPEC-03 §9)
- 이후 재진입에서는 안내 문구와 [시작하기] 없이 바로 지도를 보인다 (SPEC-03 §9)

### 참여

- 초대코드는 영문+숫자 혼용 6자리 고정이다 (SPEC-04 §2)
- [참여하기]는 6자리를 모두 입력하면 활성화하고, 누를 때 유효성 검사를 한다. 에러면 비활성화한다 (SPEC-04 §3)
- 에러 토스트 3종: 발급된 적 없는 코드, 이미 참여 중인 팟의 코드, 인원이 6/6으로 찬 팟(참여 불가). 각각 3초 뒤 자동으로 사라진다 (SPEC-04 §4, §5, §6)
- 코드가 유효하면 팟 이름, "n/6명 참여 중" 카운터, 참여 멤버 닉네임 목록을 확인 팝업으로 보인다 (SPEC-04 §7)
- 팟 최대 인원은 6명 고정이다 (SPEC-04 §7)
- [다시 입력]은 모달을 닫고 입력 화면으로 돌아가며 입력값을 초기화한다 (SPEC-04 §8)
- [맞아요]로 참여가 확정되면 여행 지도 진입 화면 위에 "OOO에 참여했어요 (n/6)" 토스트를 3초 보인다. OOO = 팟 이름, n = 현재 참여 인원 (SPEC-04 §9, §10, SPEC-03 §10)

### 설정

- 팟 이름에 변동이 생기면 [저장]을 노출하고, 누르면 변경된 이름으로 저장한다 (SPEC-17 §1)
- 팟원도 팟 이름을 수정할 수 있다 (SPEC-17 §7)
- 멤버 목록은 본인에 (ME)를 붙이고 팟장/팟원 뱃지로 구분한다. 순서는 나 최상단 고정 → 가입 순서다 (SPEC-17 §2)
- 초대코드 복사 아이콘은 클립보드에 복사하고 "초대코드가 복사됐어요" 토스트를 보인다 (SPEC-17 §3)
- [초대 링크 공유하기]는 초대 링크를 클립보드에 복사한 상태로 OS 공유 시트를 연다 (SPEC-17 §4)
- [팟 삭제하기]는 팟장에게만 보인다 (SPEC-17 §5, §7)
- [팟 삭제]를 확정하면 팟과 팟에 속한 모든 데이터를 서버에서 영구 삭제하고 초대코드도 즉시 만료한다 (SPEC-17 §5-1)
- 팟 나가기: 실행자 본인만 멤버 목록에서 빠지고 "멤버 (n)"이 "멤버 (n-1)"로 실시간 반영된다 (SPEC-17 §6-1)
- 나간 뒤 실행자는 홈/팟 목록 화면으로 자동 이동하고 완료 토스트를 본다 (SPEC-17 §6-1)
- 나간 뒤 같은 초대코드/링크로 팟원으로 재입장할 수 있다 (SPEC-17 §6-1)
- 삭제·나가기 모달의 [취소]는 모달을 닫고 팟 설정 화면으로 돌아간다 (SPEC-17 §5-1, §6-1)

## 확인 필요

- 팟 이름 규칙을 "온보딩에서 작성한 규칙과 동일"이라고 적지만 이름 규칙은 생성 화면에 있다. 가리키는 대상 확인 필요 (SPEC-17 §1, SPEC-03 §2)
- "초대 링크"의 형식과 초대코드와의 관계는 원문에 없다. 생성 화면은 "초대코드 공유하기"라고 적는다 (SPEC-17 §4, SPEC-03 §8)
- 나가기 완료 토스트 문구가 "팟에서 나갔습니다 등"으로 적혀 확정 문구가 아니다. 복사 토스트와 함께 노출 시간도 없다 (SPEC-17 §3, §6-1)
- 에러 토스트 3종의 문구는 사본에 없다 (SPEC-04 §4~§6)
- 참여로 들어온 사람의 티켓 노출 여부와 그때의 날짜 기준은 원문에 없다 (SPEC-03 §6)
- 드롭다운의 팟 정렬 순서는 원문에 없다 (SPEC-02 §5)
