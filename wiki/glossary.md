# 용어집

원문(`raw/figma/`)에 실제로 나오는 제품 용어만 모았다. 정의는 원문 표현을 줄인 것이고, 원문이 정의하지 않은 부분은 `확인 필요`로 둔다.

## 팟과 사람

| 용어 | 뜻 | 출처 |
| --- | --- | --- |
| 여행팟 (팟) | 사용자가 만들거나 초대코드로 참여하는 단위. 드롭다운으로 팟을 바꾸면 앨범 목록이 그 팟 기준으로 바뀐다 | SPEC-02 §5, SPEC-11 §1 |
| 팟장 | 팟 삭제 버튼이 보이는 유일한 멤버. 생성자가 처음 팟장이고(티켓 진입 순서 고유 1번), 팟장이 나가면 가장 먼저 참여한 멤버에게 넘어간다 | SPEC-03 §6, SPEC-17 §5, SPEC-17 §6-1 |
| 방장 | 리캡 원문에서만 쓰는 표현. 팟장과 같은 뜻인지는 `확인 필요` | SPEC-15 §1, §2-1 |
| 팟원 | 팟장이 아닌 팟 참여자. 문맥에 따라 팟 참여자 전체를 가리키기도 한다 | SPEC-17 §2, §7, SPEC-06 §6 |
| 멤버 | 팟에 속한 사람 전체(팟장 포함). 인원 표기 "멤버 (n)"에 쓴다 | SPEC-17 §2, §6-1 |
| 정원 | 팟 최대 인원. 6명 고정이며 "n/6"으로 표시한다 | SPEC-04 §6, §7 |
| 가입 순서 (참여 순서) | 팟에 들어온 순서. 멤버·프로필·이미지 자리 정렬의 기준 | SPEC-11 §5, SPEC-12 §2, SPEC-17 §2 |
| 초대코드 | 팟 참여에 쓰는 영문+숫자 6자리 코드 | SPEC-04 §2, SPEC-03 §6 |
| 초대 링크 | 팟 설정의 공유 버튼이 복사·공유하는 링크. 형식과 초대코드와의 관계는 `확인 필요` | SPEC-17 §4, §6-1 |
| 티켓 (여행팟 티켓) | 팟 생성 직후 보여주는 카드. 팟 이름, 진입 순서, 팟장 닉네임, 생성일, 초대코드를 담는다 | SPEC-03 §6 |
| 닉네임 | 프로필 이름. 1~6자(공백 포함), 중복 허용 | SPEC-01 §5 |
| 아바타 | 기본 프로필 이미지 4종 중 하나. 앨범 사진으로 대신할 수 있다 | SPEC-01 §2, §3, §4 |
| ME! 뱃지 | 본인 카드·본인 사진에만 붙는 식별 뱃지. 팟 설정 멤버 목록에서는 "(ME)" 표기 | SPEC-12 §4-4, SPEC-13 §3, SPEC-17 §2 |

## 지도와 기록

| 용어 | 뜻 | 출처 |
| --- | --- | --- |
| 여행 지도 | 팟의 첫 진입 화면이자 메인 화면. 등록된 지역을 색칠·핀으로 보여준다 | SPEC-03 §4, SPEC-05 §1 |
| 줌 단계 | 지도 확대 수준 0(국가)·1(메인)·2(시)·3(최대 줌인). 실제 수치는 [Q06](open-questions.md#q06) | SPEC-05 §0~§3 |
| 지역 | 기록을 붙이는 단위. 최대 줌인에서 선택한다. 한 팟의 한 지역에는 핀이 하나다(D-003) | SPEC-08 §3, SPEC-11 §2 |
| 기록 (여행 기록) | 한 지역에 올리는 키워드 1개 + 사진 1장 + 선택 코멘트 | SPEC-09 §3, §6-1, SPEC-10 §7 |
| 핀 | 1명 이상이 기록한 지역에 지도 위로 보이는 표시. 리캡에서는 개수 집계 단위로도 쓴다([Q14](open-questions.md#q14)) | SPEC-08 §1, SPEC-15 §1 |
| 키워드 | 기록의 분류. 맛집 / 디저트 / 힐링 / 액티비티 / 사진 중 1개 | SPEC-09 §3 |
| 스티커 (키워드 스티커) | 키워드를 나타내는 아이콘. 지도 썸네일, 기록 카드, 코멘트 말풍선에 쓴다 | SPEC-05 §1, SPEC-10 §13, SPEC-12 §4-3 |
| 썸네일 스티커 | 지도에서 구역을 대표하는 스티커 1개. 가장 많이 뽑힌 키워드, 동률이면 ㄱㄴㄷ순 첫 번째([Q05](open-questions.md#q05)) | SPEC-05 §0, §1, §3 |
| +N 툴팁 | 해당 구역(국가·도) 안에 등록된 지역 수. 타인만 등록한 지역도 센다 | SPEC-05 §0, §1 |
| 기록하기 툴팁 | "{지역이름} 기록하기" 버튼. 팟원만 기록하고 나는 안 한 지역 중 가장 최근 1곳에만 붙는다 | SPEC-08 §2 |
| 바텀시트 | 지도에서 기록이 있는 지역을 누르면 뜨는 시트. 키워드와 멤버 슬롯을 보여준다 | SPEC-08 §4-1, §5-1 |
| 슬롯 | 바텀시트에서 멤버 한 명에게 배정된 자리. 팟 인원에 따라 개수가 달라진다 | SPEC-08 §6 |
| 코멘트 | 사진에 붙이는 한 줄 설명. 선택 입력 | SPEC-10 §7, §8 |
| 지역명 뱃지 | 업로드 화면의 지역 이름 표시. 완료 화면에서는 키워드 색상을 배경으로 쓴다 | SPEC-09 §2, SPEC-10 §9 |
| 줌인 가이드 | 온보딩은 봤지만 첫 기록을 안 한 사용자에게 보이는 지도 조작 안내 툴팁 | SPEC-07 §2 |

## 앨범과 리캡

| 용어 | 뜻 | 출처 |
| --- | --- | --- |
| 여행 앨범 | 하단 탭바의 탭. 팟의 기록을 지역별 카드 목록으로 본다 | SPEC-06 §6, SPEC-11 §2 |
| 여행 지역 카드 | 앨범 목록에서 방문한 지역마다 1장씩 생기는 카드 | SPEC-11 §2 |
| 기록 인원수 카운트 | "n/N명". n = 그 지역에 사진을 올린 멤버 수, N = 팟 멤버 수 | SPEC-11 §4, SPEC-12 §2 |
| 기록 카드 | 지역 상세 그리드에서 멤버 1명의 카드. 기록 유무에 따라 구성이 달라진다 | SPEC-12 §4 |
| Zzz (zzZ) | 아직 올리지 않은 멤버 자리를 나타내는 그래픽. 표기가 원문마다 다르다 | SPEC-11 §5, SPEC-12 §4-2 |
| 여행 이미지 상세 보기 | 사진 1장을 크게 보는 화면(사진 뷰어). 앨범 원문 3개가 같은 제목을 쓴다 | SPEC-12 §4-3, SPEC-13 §5 |
| 리캡 | 팟의 여행을 이미지 한 장으로 요약해 내보내는 기능 | SPEC-06 §5, SPEC-14 §4 |
| 리캡 카드 | 여행 통계와 지도를 담은 내보내기용 이미지 | SPEC-15 §2 |
| 스토리용 이미지 | 스토리 비율의 리캡 이미지. 비율 수치는 [Q13](open-questions.md#q13) | SPEC-15 §4 |
